# The freeze lifts for the access language

> **Replaced** by [Groundwork is no longer frozen](2026-10-17-groundwork-is-no-longer-frozen.md) (2026-10-17): the whole freeze is lifted, not only for the access language.

> Changes [Groundwork is frozen](2026-10-15-groundwork-is-frozen.md) in part.

**Decision:** Groundwork builds [the access language](2026-10-17-access-rules-are-sentences-in-groundworks-language.md), and the shapes it replaces go. Everything else stays frozen: bells, styles, and every other part.

**Why:** who may see what was the one open question, and it was holding every access rule the large app needs: those endpoints run as the system, unchecked, until the app can say its rules. The answer is the line between the app and Groundwork, so it can't be solved in the app alone.

**The price:** Groundwork changes again while it is frozen, and both running apps change with it.

**Instead of:** staying frozen and leaving those endpoints unchecked; lifting the freeze for everything.
