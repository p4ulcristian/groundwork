# groundwork.browser.wire

How shaped data travels as text and comes back as what it was, in the
browser: an Instant and a Day (`groundwork.browser.wire.time`), a decimal's
text or big.js (`groundwork.browser.wire.big`), an id as text. The server's
side is [groundwork.server.wire](../../server-code/wire/README.md), with
its decisions. ClojureScript only.
